| 项目 | 方案 | 待确认 |

| 功能 | 官方计划书、讲解包、客户跟进卡 | 是否包含 Dify 问答与参数抽取（M2b）、知识问答（M3） |

**真实授权任务**：客户已授权、经纪有权处理、经真实保司门户执行、以官方 PDF 为结果的任务。模拟任务和内部测试任务不计入。

**统计口径**（依据交付计划 §7）：

- 每个任务记录“最终结果”（成功交付／取消／失败）和“是否人工介入”两项。
- 自动完成 = 成功交付且全程无人工介入。
- 自动完成率的分母为已接受的有效任务；经纪主动取消单列；外部门户错误计入失败或人工，不从分母剔除。目标值待业务确认（交付计划暂定 ≥90%）。小样本通过不代表长期 SLA。
- 耗时 = 从经纪确认参数到文件可下载，含排队；自动与人工分开统计 P50／P95。

## 6. 立即暂停条件

出现下列任一情况，立即暂停受影响功能，修复并重新验证后才能恢复（交付计划 §7）：

1. **串客户文件**：任一经纪看到或下载到不属于该任务或该客户的 PDF、讲解包或跟进记录。
2. **越权泄露**：经纪或机构访问到无权访问的客户、任务、文件、聊天或审计数据。
3. **错误关键数字被交付**：已交付或已导出给客户的材料中，关键数字（金额、年度、币种、保证属性等）与官方 PDF 或确认参数不一致。

建议同样立即暂停（待业务确认）：

4. 模拟文件被当作官方文件交付（[AGENTS.md](../../../AGENTS.md) §2 第 2 条）。
5. 门户凭据、Cookie、API Key 出现在日志、聊天或审计正文中（AGENTS.md §2 第 3 条）。

暂停后的处理：

| 步骤 | 内容 | 负责人 |
| --- | --- | --- |
| 1. 宣布暂停 | 确定范围：单产品／单功能／全部 | 待确认 |
| 2. 停止新任务 | 按[部署与运维需求](deploy-ops.md)第 6 节执行，不切换到 mock | 待确认 |
| 3. 保全证据 | 保留审计、日志、文件 hash，不删除、不覆盖 | 待确认 |
| 4. 评估影响 | 涉及哪些经纪、客户、文件；是否需要通知客户或其他方，由隐私／法务判断 | 待确认 |
| 5. 修复与复验 | 修复后重跑相关验收用例并附证据 | 待确认 |
| 6. 恢复 | 业务负责人签字后恢复 | 待确认 |
