## 阶段 4：Dify → 后端工具

**Dify workflow 不调用后端工具；M2b 开发版采用后端编排。** 后端在回复出口保存合规审计，progress 和 followup 直接读取经纪授权的数据，因此不需要 Dify 回调或工具节点。已验证 Dify API 容器能经 `host.docker.internal` 到达一个只监听本机回环的临时探针，不需要把后端绑定到局域网地址。

现有 gateway 要求短期令牌、由令牌生成的请求签名、时间戳、nonce 和数据范围。短期令牌不能进入 Dify 运行日志或模型输入，因此 M2b workflow 不传令牌、不调用后端工具；也没有提供绕过签名的替代接口或放宽 gateway 校验。进度数据源仍未配置，只有本地演示计划书任务可查。
